# YOLOv12 Drug Recognition System

## Body

YOLOv12 Drug Recognition System Based on Deep Learning YOLOv12 Drug Recognition Detection System (YOLOv12+YOLO dataset + UI interface + login registration interface + Python project source code + model)

Drug recognition is of great significance in medical safety and drug management. This paper proposes a drug recognition detection system based on deep learning YOLOv12, which can efficiently and accurately recognize eight common drugs (including Cipro 500, Ibuprofen 600 mg, etc.) as well as different colored pills (blue, pink, red, white). The system combines the high-precision detection capability of the YOLOv12 algorithm and integrates a user-friendly UI interface and login registration function. Experimental results show that the system performs excellently on custom YOLO datasets, with an average precision (mAP) of 98%, reaching a high level, meeting the needs for rapid drug recognition in practical scenarios. In addition, the system provides complete Python project source code and pre-trained models, facilitating subsequent research and expansion.

✅ User login registration: Supports password verification and security validation.
✅ Three detection modes: Based on the YOLOv12 model, supports image, video, and real-time camera detection, accurately recognizing targets.
✅ Dual-screen comparison: Displays the original scene and detection results on the same screen.
✅ Data visualization: Real-time table displaying the category, confidence, and coordinates of detected targets.
✅ Intelligent parameter adjustment: Offers a confidence slide bar to dynamically optimize detection accuracy, adapting to different scene requirements.
✅ Sci-fi style interactive interface: Dark theme combined with dynamic light effects, reducing visual fatigue and improving operational experience.
